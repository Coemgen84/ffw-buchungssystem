### Branding Architecture (Post-Change)

```
AppLogo component
├── custom_logo_url set in DB? → Show org logo
│   ├── custom_logo_text_line1/2 also set? → Logo + text side by side
│   └── No text? → Logo only
└── No custom_logo_url → Fallback to /ui/seatsurfing.svg (Seatsurfing original)
```

Organization name always from DB (`organizations.name`), shown as `<h3>` on login.

### Critical Build Pipeline Note

The Dockerfile uses `ADD ui/build/ /app/ui/`. This means:
- UI source changes (`ui/src/`, `ui/public/`) are NOT rebuilt inside Docker
- `npm run build` must run BEFORE `docker buildx build`
- Failure to rebuild UI results in stale SVG/code being served from Docker cache

**Correct sequence:**
```bash
cd ui && npm run build     # First!
cd .. && docker buildx build --load -t ffw-test-app:1.89.0 .
```

## Pitfalls Encountered This Session

1. **Docker CE update stops containers with `restart: no`** — always use `restart: always` or `unless-stopped`
2. **Stale UI build in Docker** — `npm run build` must run before Docker build
3. **i18n merge trailing commas** — JSON spec forbids trailing commas; automated fix needed
4. **SSH remote editing of Go files** — shell escaping through SSH + sed is fragile; Python scripts via SCP are safer
5. **rsync excluding .git/objects** — breaks the git repo; must sync .git separately
